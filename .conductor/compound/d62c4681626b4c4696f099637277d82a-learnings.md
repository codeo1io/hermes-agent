  GitHub — recover via `gh api commits/<full-40-char-head>/check-runs` and close the PR / delete
  `conductor/ci-*` refs manually. **(2026-10-18 addendum, paid-for by F0: quote the query with
  the full 40-char SHA and tally against `total_count` — an abbreviated-or-typo'd SHA can 404/422

  delegate tmp dir and crashes the runner's finally-block.
